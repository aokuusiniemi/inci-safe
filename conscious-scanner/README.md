# INCI-Safe — Scan & Check

INCI-Safe is a web app for scanning personal-care product barcodes and checking ingredients against customizable flag rules and legal notices. It helps users identify potentially concerning ingredients and view product recalls or lawsuits.

## Features
- Barcode scanning using camera (QuaggaJS)
- Manual UPC/EAN lookup
- Ingredient flagging with editable rules
- Recent scan history
- Product recalls and legal notices
- Import/export product datasets (CSV/JSON)
- Mobile-friendly responsive design

## Getting Started
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Use the camera scan or enter a UPC/EAN manually.
4. Add or edit flag rules as needed.

## Data Files
- `data/products.json`: Main product dataset
- `data/seed-products.json`: Seed products for first-time use
- `products.csv`: Example CSV for import

## Development
